# Security

This site is the published output of a personal trading dashboard. It is a
static page: there is no login, no account, no database behind it, and it
collects nothing from visitors.

## What is here

Market-derived data only: a nightly scan of a public watchlist, breakout
alerts, and an aggregate scorecard of how those picks performed. Nothing
personal and nothing account-related is published here, in any form.

## What is not here

Personal data (routine, sleep, training, notes) and anything account-related
(positions, trades, balances) never leave the private system that builds this
site. Publication is deny-by-default: a file must be explicitly allowed, and
account-shaped files are refused outright and stop the build.

## Reporting a problem

If you find something on this site that looks like it should not be public,
please open an issue in this repository with what you saw and where. Do not
include anything sensitive in the report.
