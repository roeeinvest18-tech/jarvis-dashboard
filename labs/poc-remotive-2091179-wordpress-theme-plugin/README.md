# Working PoC — WordPress Theme & Plugin Developer (Steward Web Development)

## Overview
- **Track:** `web_dashboards`
- **Target Need:** The client needs a full-stack WordPress developer to build and maintain custom themes and plugins over a five-month contract.
- **Included Files:**
  - `index.html` + `app.js` + `styles.css` — Interactive browser prototype
  - `poc.py` — Zero-dependency Python reference implementation (verified via `--self-test`)
  - `sample_input.json` / `sample_output.json` — Verified fixture input & output

## Quick Run
```bash
python poc.py --self-test
```

## Tailored Architecture
Built on a full-stack WordPress implementation utilizing custom post types, REST API endpoints, and optimized plugin hooks to ensure secure, scalable, and maintainable execution over the five-month contract lifecycle.
